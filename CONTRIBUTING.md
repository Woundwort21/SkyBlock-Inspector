# Contributing

Thanks for helping improve SkyBlock Inspector.

- Search existing GitHub Issues before opening a new one.
- Report bugs with the Minecraft version (26.2 or 26.3), mod version, reproduction steps, and relevant errors.
- Keep changes client-side and informational; do not add automation, movement modifications, or packet spoofing.
- Please submit changes as pull requests and say which Minecraft versions you tested.
- Don't submit proprietary or third-party copyrighted code/assets without appropriate permission.
